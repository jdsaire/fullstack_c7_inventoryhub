Integration Architecture & Resilience Pipeline

1. Synchronized Route Alignment: Front-end HttpClient issues GET requests to /api/productlist, matching back-end endpoint mappings in Program.cs and preventing route mismatch 404 errors.

2. Demo-Permissive CORS Policy: Middleware registers builder.Services.AddCors() to resolve ICorsService dependencies, applying AllowAnyOrigin(), AllowAnyMethod(), and AllowAnyHeader() for seamless cross-origin development communication.

3. Typed Exception Isolation: Client-side deserialization isolates JsonException from network transport failures (HttpRequestException, TaskCanceledException), presenting actionable feedback rather than unhandled crashes.

4. Standardized Nested Category Schema: Both server responses and client models bind strongly-typed nested objects (Category.Id, Category.Name) with PropertyNameCaseInsensitive = true for robust camelCase/PascalCase interoperability.

[SIM] Simulated Inventory Snapshot: This GitHub Pages demonstration is powered by a bundled JSON snapshot with nested category schemas. The real ASP.NET Core Minimal API service runs locally and in automated test fixtures.
