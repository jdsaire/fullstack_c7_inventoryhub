# handoff

The record of how this repository was built.

Each version of the project that was planned and executed as a unit gets a folder here, holding
the plan it was built to and the report of what actually happened. The point is that someone
arriving later can see what was intended, what was built, where the two differed, and why.

| Version | What it covers |
|---|---|
| [v1/](v1/README.md) | The first build: all four graded Activities, plus an attempted (and deferred) Render deployment. |

## Why this exists

The code and its documentation describe the project as it now stands. They do not record the
decisions taken along the way — which options were weighed, what was discovered mid-build that
nobody planned for, why deployment isn't live. That reasoning is expensive to reconstruct and
easy to lose, so it is written down here instead.
